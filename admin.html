Publishing

Press Save changes at the top and your website updates by itself in about a minute. The first time, connect this page to your GitHub website (one time only).

Connect to GitHub (one time)
  1. On github.com click your picture, then Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name: Website admin. Expiration: the longest allowed. Repository access: Only select repositories, then choose your website repository.
  3. Permissions, then Repository permissions, then Contents: Read and write. Click Generate and copy the token.
  4. Paste it above and press Test connection.
The token stays only in this browser. Do not share it. When it expires, make a new one and paste it here.
